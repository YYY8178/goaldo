# GoalDo 项目上下文

> 最近核对：2026-08-16（Asia/Shanghai）
> 公开基线：`main` @ `5758b98`（tag `v0.1.0`）

## 一句话定位

GoalDo 是一个开源 AI 项目推进系统：把模糊目标转换成阶段、模块、任务、步骤、依赖、知识、交付物和验收标准，并根据执行证据持续调整路线。

## 公开仓库包含

- React + Vite 项目工作区；
- 本地 Express 服务与模板回退规划能力；
- Cloudflare Worker、D1 migrations、密码登录、邀请、管理和 API 连接能力；
- 9 种项目类型与结构化规划模型；
- 自部署、安全、贡献、许可证和商标说明。

## 明确不包含

- 官方托管服务的用户、项目、邀请或数据库导出；
- 真实域名、Cloudflare Access 策略、数据库标识或管理员配置；
- 模型 API Key、会话签名密钥、加密密钥或托管凭据；
- 官方托管服务的部署流程和运营政策。

## 技术结构

```text
React + Vite
    │
    ├── Express（本地开发，可选 OpenAI 规划）
    │
    └── Cloudflare Worker（生产 API、认证、D1、加密连接）
```

## 当前阶段

公开、自部署基线已发布为 `v0.1.0`。是否继续把 GoalDo 作为独立产品推进、以及下一阶段唯一目标是什么，仍需维护者明确决定。公开基线与任何历史本地工作树之间的差异必须先审查，再按小范围 PR 引入。
