# GoalDo / 项目简介

## One sentence

**GoalDo is an open-source AI project operating system that turns an ambiguous goal into an executable project map, then helps the user keep the route aligned with real progress.**

**GoalDo 是一个开源的 AI 项目推进系统：它把模糊目标变成可执行的项目地图，并根据真实执行结果持续调整路线。**

## What it does

A GoalDo project can contain stages, modules, tasks, detailed steps, knowledge prerequisites, dependencies, resources, deliverables and acceptance criteria. The system combines a stable template backbone with AI personalization, rather than relying on an unstructured one-off answer.

It can support many goal types, including building a website or app, running a content account, developing hardware or physical products, research, startup validation and AI agents.

## What it is not

GoalDo is not a generic chatbot, a static course outline or a promise that AI can replace project ownership. The person or team remains responsible for decisions and execution; GoalDo is designed to make that work clearer and more verifiable.
