# GoalDo 决策记录

## D-001：公开版与闭源版使用两个正式仓库

- 日期：2026-08-16
- 状态：生效
- 决策：`YYY8178/goaldo` 提供公开、自部署版本；`YYY8178/goaldo-private` 保存闭源正式产品与托管版本。官方托管服务的生产配置、数据与运营策略不由公开仓库代表。

## D-002：数据与密钥不进入公开基线

- 日期：2026-08-16
- 状态：生效
- 决策：公开仓库只保留示例与占位符。用户数据、真实身份、数据库、域名配置、Cloudflare 标识和所有密钥均不得提交。

## D-003：开源版下一阶段单独决定

- 日期：2026-08-16
- 状态：生效
- 决策：`v0.1.0` 发布后，在没有明确的开源版目标和验收标准前，不继续堆功能。闭源版的产品进度不自动决定公开仓库的路线。

## D-004：两个版本不自动同步

- 日期：2026-08-16
- 状态：生效
- 决策：不把闭源仓库或混杂本地工作树整体推入公开仓库。通用能力按文件和功能核对隐私、许可证、部署边界与测试后，通过独立小范围 Draft PR 移植。
