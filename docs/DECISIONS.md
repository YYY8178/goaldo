- 日期：2026-08-16
- 状态：生效

## D-002：数据与密钥不进入公开基线

- 日期：2026-08-16
- 状态：生效
- 决策：公开仓库只保留示例与占位符。用户数据、真实身份、数据库、域名配置、Cloudflare 标识和所有密钥均不得提交。

## D-003：下一阶段先做产品方向决定

- 日期：2026-08-16
- 状态：生效
- 决策：`v0.1.0` 发布后，在没有明确的下一阶段目标和验收标准前，不继续堆功能。先决定独立推进、限定范围继续，或暂停维护。

## D-004：历史本地改动必须逐项对账

- 日期：2026-08-16
- 状态：生效
- 决策：不把混杂未提交改动的本地工作树整体推入公开仓库。需要保留的能力按文件和功能核对隐私、许可证、部署边界与测试后，通过小范围 Draft PR 引入。
